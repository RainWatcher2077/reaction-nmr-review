# 可复用流程验收

用明确标为合成/教学的测试资料，单独放 `verification/`。独立测试 agent 阅读已完成技能，给最少原始测试材料，不给预期答案、故障提示或下面的评分结论。它实际写出输出；主 agent 根据原始证据判断行为，不以关键词匹配算通过。若有真实子 agent，应包含一次 C 的新上下文盲读、D/E同版本独立评估和新F原证据回看。工具容量不足则分批并记录。

六项最低行为案例：

| 案例 | 原始测试材料 | 评分关切 |
|---|---|---|
| 文献只有类似物 | 提供目标与已取得的类似物结构/数据，SI不可读 | 不宣称完全一致已报道；写明结构差异与核实范围，不把SI缺失补成数据 |
| 无MS | 给可读谱学观察，不给MS或独立分子式 | 完成可做的分析；不强制补MS，不把结构计算式当实测，不启动缺公式的完整CASE |
| 全候选不符 | 每个候选都有明确可回看的关键矛盾 | 保留“所有候选均不匹配”，不把得分最高者写成鉴定 |
| 混合物 | 两组自洽信号加未解释信号 | 保留混合可能、溶剂/杂质/构象等合理替代，不把所有峰强制归一结构 |
| MS加合误标 | 正离子m/z与给定[M+H]+不合，却与另一加合解释相合 | 真复算模式/价态/加合/误差并修正，不套标签，不借MS强称同分异构或绝对构型 |
| 同用错误峰表 | 原始谱学来源与共享表不一致，D/E等复用同一错误 | F实际回看原始来源，发现提取问题；创建v2、保留v1、定向重评，不能算多票独立支持 |

另查：结构歧义先确认；C身份泄漏披露；缺真实子agent的降级；文献隐私；0至3副产物门控；无依赖时明确失败；共享记录不被覆盖；修订原因和未解决分歧被保存。结构工具应实际检查有效SMILES、立体/盐、无效输入、依赖缺失与拒绝覆盖，输出图还需查看。

验收记录写清：日期、技能版本hash、测试输入、实际工具/agent ID、角色、上下文设置、实际读取的原证据、输出路径、通过/失败及依据。测试可用虚构文献卡，但必须显眼标“合成测试，非真实引用”，不给伪造DOI；它只能验证分类和访问范围处理，不能声称真实文献检索已验证。合成峰表/示意谱图不能证明真实谱学准确性。只有流程测试时结论写“流程测试通过，真实谱学能力尚未验证”。
