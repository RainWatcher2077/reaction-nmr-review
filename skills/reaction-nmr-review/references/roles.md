# 子 agent 角色协议

所有角色：只读主 agent 白名单输入和下列本角色依赖；只写自己输出目录，不修改共享文件或原谱，不主动读取其他角色目录（F 除外）。使用真实工具；不可用时返回缺失状态。不得嵌套派生。数值、峰归属、公式和引用必须有来源，不编概率。返回结构见 templates.md。

## 派发消息骨架

主 agent 填好此消息后以真实工具派发，不要把整个用户请求附给 C：

```text
角色：A/B/C/D/E/F；run_id：中性代号
读取技能和本角色协议：<skill path / references/roles.md 的角色段>
允许读取：<显式文件、必要工具源码/帮助、文献权限>
禁止读取：<身份材料/其他角色输出，按角色填写>
允许写入：<roles/X 绝对路径>
输入版本与 SHA-256：<如适用>
工具：<ailsa-nmr skill 路径、已核实 wrapper、Python；如适用>
任务：<本角色段的要求>
预期文件：<以下约定>
返回：status、真实写出路径、证据位置、限制和待主 agent 处理的问题
```

C 的派发由主 agent 单独重写，`fork_turns="none"`。仅传中性谱图路径/采集元数据/工具依赖路径，不传 manifest、结构、反应、分子式猜测或 A/B。共享系统/开发者上下文可能仍含路径线索；记录实际暴露范围，不声称硬隔离。D/E 也使用新上下文；尤其 E 不继承 D。

## A：反应推理

输入：确认的原料、目标、条件及对应关系；可用公开文献。输出 `roles/A/reaction.json` 和必要依据。

- 目标另列：反应是否合理、可能成为主产物的依据与限制；不把“常见反应”当本样品证明。
- 提出 0–3 个值得谱学检验的副产物（目标不计数），可含未反应原料或后处理产物，但需明确标签。给稳定 ID、明确连接/立体/电荷的 SMILES、工具计算式及校验状态、形成路径和关键假设。结构不确定时给待确认分歧，不生成假精确 SMILES。
- 区分 `literature_supported`（有具体来源及适用范围）和 `mechanistic_hypothesis`。计算式交由主 agent 的结构门统一复验，A 不具备工具时留空并说明。
- 不声称候选穷尽，不给生成概率，不读 C 来反推候选。

## B：文献检索

输出 `roles/B/literature.json`、必要的公开原文/SI及检索日志。

- 记录检索日期、公开查询词、来源、访问失败及隐私导致的范围限制。不得把未公开 SMILES、独特反应组合、谱图或截图上传；只做已授权范围的查询。
- 分类逐条：`exact`（连接、立体、电荷/盐形式确切一致且证据足够）、`close_analogue`（明确列出差异）、`reaction_precedent`（支持反应先例，不直接证明目标存在）。未核实结构不能称 exact；立体或盐形式不明就降级或明确仅连接一致。
- 尽量打开原文与 SI，对每项给 DOI/可靠原始链接、化合物编号、原文/SI页码（PDF页和印刷页区分）或节/图/表位置、结构位置、实际可读的实验数据（核种、频率、溶剂、δ、积分、J、MS原注释等）。不得从类似物迁移数值当目标实测。
- 只有摘要、登录墙、无法读 SI 或部分页面可见时，标实际核实范围。搜索结果片段只能做线索。
- “未检索到”只说明此次检索，不写“从未报道”。找到 exact 也不能替代后续实验核对。

## C：独立读谱

输出 `roles/C/spectral-facts-initial.json`，以及 `roles/C/extraction/` 中的命令日志、截图位置、人工转录及原始工具输出。先保存初始谱学约束，再允许进入任何候选匹配阶段；后者由新 D/E 承担。

- 读取 ailsa-nmr 与本技能 ailsa-integration.md，只接谱图和必要采集元数据。即使环境中可访问，也不浏览其他任务目录、历史/记忆、`.planning`、benchmark真值或身份侧录，不运行目标/候选搜索。
- 在实际能力范围读 Bruker/支持的 JCAMP/显式移位表；图/PDF需视觉核对或带位置的转录。当前 pick 输出不自动提供积分/多重性/J；没有原始观察依据的字段填 unknown。保存处理参数与错误，不把退出码当科学成功。
- 逐峰保留 ppm、强度与积分的区别、积分归一化依据、多重性、J及单位、不确定度/重叠、核种、源谱位置、二维交叉峰坐标/符号和实验类型。没有这些数据就不填。碳信号数与非等价碳数分开。
- 溶剂/水/杂质峰先标 `possible`，有溶剂、温度及位置依据才提高归属确定性，不为“清谱”删除不明峰。关注额外信号组、积分不协调、重复组、旋转异构/构象及交换；“可能混合物”与已证明组分分开。
- `observation` 是原始可见事实，`interpretation` 是官能团/连接/混合物等解释，二者分栏。每个解释引用观察 ID。共享事实中不带目标/候选拟合结论。
- 记录 `blindness.context_inheritance`、收到的文件、路径/文件名/图注/元数据泄漏、未读目录、完整性限制。若看见结构名/反应图则明确“盲判不完整”。

## D：目标核对

输入：同版本共享事实及可访问原谱、目标结构/计算产物、B 的 exact 文献（及单独标记的其他类别）、采集与MS信息。输出 `roles/D/target-review.json`，可含本地预测产物。

按共享标准逐项对照目标。引用观察与原证据 ID，给出支持、关键矛盾、未解释信号、无法判断项和可区分实验。准确文献的比较须考虑溶剂/频率/温度/浓度/盐形式差异；不能机械套一个普适 ppm 阈值。候选预测不是实测，不以原子数代替预期可分辨信号数，记录预测缺失及覆盖率。核对原子映射，不能靠重新排序 δ 伪造逐原子归属。

有 MS 时用实测离子模式、加合离子/电荷及理论离子质量复算，记录 ppm = `(m/z_obs - m/z_calc) / m/z_calc * 1e6`。用可靠常数/工具，区分中性原子质量和带电离子质量，不能简单把质子当氢原子。考虑同位素、碎片、溶剂/盐加合及多电荷；缺模式或原始标注则保留替代解释，不自行定离子。MS同分异构不能排他；无 MS 不阻断。

## E：副产物核对

输入：与 D **完全相同版本**的事实、原谱、元数据和判定标准，另加最多 3 个副产物与其文献。不读取 D 的文件或主 agent 对 D 的摘要。输出 `roles/E/byproduct-review.json`。

逐个执行 D 的相同核对标准，并按单组分/混合物两种假设检验。未解释峰可能来自溶剂、杂质、混合、构象/异构等；不可全归于候选。若某候选只解释少量峰，列出其余峰及排他性缺失，不能当已确认组分。零个副产物时返回 `complete_no_candidates`，不临时制造候选。重大新假设交主 agent，再进入版本化候选重评，不私改共享集合。

## F：独立交叉核查

使用新 `fork_turns="none"` agent；未参与 A—E 候选生成。输入：原谱、采集/MS信息、共享事实和候选、结构产物、文献原文/SI及 A—E 结果。输出 `roles/F/cross-check.json`。

主动找错，至少：

1. 回看用户结构原图（可访问时）及工具渲染，对照 SMILES/分子式、键、取代、形式电荷、盐/溶剂化物、同位素、未指定/遗漏立体。SMILES能解析不等于转录正确。
2. 实际打开文献结构与谱学数据位置，检查是否把类似物/反应先例当 exact，数值和实验条件是否误抄，核实范围是否夸大。
3. 回看可访问原谱，不只读共享峰表：优先检查承载结论的峰、积分归一化、异常信号和二维相关。追踪处理参数/峰来源，检查错误峰表是否污染多个角色。记录实际回看的页/区域/实验与方法。
4. 检查氢数、对称/重叠、碳计数、二维原子映射和归属是否自洽；是否忽略关键矛盾、因预期反应强行解释。
5. 追溯证据父来源；多个 agent 复用同一峰/文献/数据库不是多份独立证据，预测数据库记录不是实验记录。
6. MS存在时复算模式/加合/价态、理论 m/z、误差、同位素/可能碎片。标注不等于验证。
7. 检查“候选中相对最好”有无被写成鉴定、构型确定或未经校准概率；若全部不符/证据不足必须允许不选。

每项发现给 issue_id、严重度、原证据位置、错误内容、受影响角色/结论、复核建议。记录 `raw_evidence_reopened`，不可访问时如实列缺口；没有原始数据时不能声称交叉核查通过。主 agent 指派修正后，F 对照新版本与原证据核查该修改，不靠多数票。
